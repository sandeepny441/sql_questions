# 04 — Anatomy of a Rate Sheet

**Prerequisite:** 03 — Introduction to Rate Sheets

**Goal:** Be able to open any wholesale rate sheet and identify each region: header, program blocks, rate/price grids, adjuster tables, notes, and lock-period columns.

## Concepts covered
- The standard layout: header → programs → grids → adjusters → notes
- How rows (rates) and columns (lock periods) interact
- How multiple product blocks coexist on one sheet (Conv, FHA, VA, Jumbo, Non-QM)
- The distinction between base price and net price

## Jargon

| # | Term | Definition |
|---|------|------------|
| 1 | Header Block | Top of the sheet: lender name, date, effective time, contact info, hotline. |
| 2 | Program Block / Product Block | Section of the sheet for one loan program (e.g., "30-Yr Fixed Conforming"). |
| 3 | Grid / Pricing Matrix | Tabular area of rates × lock periods. |
| 4 | Rate Column / Note Rate Column | Left-most column listing offered rates in increments (usually 0.125%). |
| 5 | Lock Period Columns | Columns for 15, 30, 45, 60, 75, 90-day locks. |
| 6 | Increment | Standard rate step on the grid, typically 1/8% (0.125%). |
| 7 | Best Execution Row | The rate offering the best net price for a given scenario (highlighted by some sheets). |
| 8 | Cap Row / Floor Row | The highest and lowest rates listed for that program. |
| 9 | Adjuster Table | Section listing price hits/credits for loan attributes (FICO, LTV, occupancy, etc.). |
| 10 | Stack | The full set of adjusters applied to a single loan. |
| 11 | Base Price | Price from the grid before adjusters. |
| 12 | Net Price | Base price ± all adjusters. |
| 13 | Worst-Case Pricing | Default to the worse of two pricing options when a lock spans a reprice. |
| 14 | Footer / Notes | Disclaimers, lock desk hours, reprice policy, contact lines. |
| 15 | Lock Desk Hotline | Number/portal for lock requests and extensions. |
| 16 | State Page / State-Specific Sheet | Some sheets vary by state; brokers must pull the correct version. |
| 17 | Color Coding | Many sheets shade premium rows green and discount rows red. |
| 18 | Sheet ID / Version Number | Identifier the lock desk uses to confirm which sheet a loan was priced on. |
