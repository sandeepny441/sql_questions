Layman Definition

Linear regression is a smart way to draw one line through a cloud of points so the line gets as close to the data as it can overall.

What To Notice

If the red line is badly placed, the dashed gaps get longer. When the line fits the pattern well, those gaps shrink and the total error drops.

Technical Definition

Ordinary least squares chooses the slope and intercept that minimize the sum of the squared residuals between the observed values and the fitted line.
